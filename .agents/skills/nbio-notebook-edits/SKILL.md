# Notebook edits with `fastcore.nbio`

Use this skill for any `.ipynb` inspection or edit.

1. **Never parse an `.ipynb` as JSON manually** to locate or alter cells. Do not use `json.load`, direct file replacement, or `view_file`/`edit_file` against notebook files.
2. List cells with `notebook_cells(path)`, then inspect the selected cell with `view_cell(path, cell_id)`.
3. Edit an existing cell with `edit_cell(path, cell_id, commands)` using addresses copied from `view_cell`.
4. Add a cell with `add_cell(path, source, index, cell_type)`.
5. When code runs in an nbdev project, edit the notebook source of truth and regenerate generated modules with `nbdev-export`; never hand-edit an autogenerated module.
6. After a notebook edit, run the project’s documented tests/export command and report the verified result.

For code that needs notebook manipulation outside agent tools, use `fastcore.nbio` (`read_nb`, notebook/cell APIs, and `write_nb`) rather than raw JSON.
