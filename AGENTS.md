# Working in Ramabana

Before you write code, check kosha first. The answer is usually already in this repo or an installed package.

Coding practices live in the code. Read the `coding_patterns` skill (`nbs/09_coding_patterns.ipynb`) before writing, reviewing, or refactoring.

The notebooks in `nbs/` are the source. Every file in `ramabana/` is generated. Edit the notebook, then `nbdev-export`. Never hand-edit a generated file, and never parse an `.ipynb` as JSON.
