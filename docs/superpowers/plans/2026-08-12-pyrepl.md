# pyrepl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One terminal holding a Python prompt whose namespace belongs to the user and a Ramabana agent that reads it through Dhrishti's sandboxed overlay without being able to rebind it.

**Architecture:** A private `ipykernel` serves its own namespace over Dhrishti's HTTP API. Ramabana's Python tools point at the ungated `/agent/` half of that API, so "reads but never rebinds" is enforced by the process that owns the namespace rather than by convention. The terminal is the existing `Ui` subclassed with a `python`/`agent` mode.

**Tech Stack:** nbdev, `jupyter_client.AsyncKernelManager`, `dhrishti.serving`, `teleprint` (Compositor/Buffer), `rich`, `codeop`, pytest + `pyghostty`.

**Spec:** `docs/superpowers/specs/2026-08-12-pyrepl-design.md`

## Global Constraints

- **This is an nbdev project. Edit `nbs/11_pyrepl.ipynb`, never `ramabana/pyrepl.py`.** The module is generated. Run `nbdev-prepare` (hyphen) before every commit; it exports, tests, cleans and regenerates `ramabana/__init__.py`, `nbs/llms.txt` and `nbs/sidebar.yml`.
- **4-space indentation.** `reference/pyrepl.py` is tab-indented; every ported line must be reindented.
- **`tests/test_pyrepl.py` is the existing contract and must not be edited to fit the code.** Its three tests are the acceptance gate for Tasks 1, 3 and 4.
- **The `pyrepl` extra is already in `pyproject.toml`**: `pyrepl = ["dhrishti>=0.1.2", "jupyter-client>=8.6.3"]`. Add `ramabana[pyrepl]` to the `dev` group and the `all` extra in Task 1. Every dhrishti and jupyter_client import is inside a function body, never at module level.
- **fastcore idioms** (`store_attr`, `patch`, `L`) and one-line docstrings where one line does; the repo's house style puts the *why* in comments above the code.
- **Ramabana never reads the owner token.** Not in attach mode, and not in own-kernel mode except through `/promote`.
- Notebook is `nbs/11_pyrepl.ipynb` with `#| default_exp pyrepl` (`10` is `10_spec.ipynb`).
- Verified fact to rely on: `dhrishti.serving.active()` returns entries shaped `{'name','port','pid','cwd','base','started'}` — `base` is present, so attach never builds a URL from a port.
- Verified fact to rely on: installed `dhrishti==0.1.2` has `serve_in_kernel(port=8000, name=None, profile='minimal', agent='restricted', token=True, session_dir=None, agent_session_dir=None)`.

```python
#| export
@dataclass
class ExecOutcome:
    "One kernel request in nbformat's output shape."
    ok: bool = True
    outputs: list = field(default_factory=list)
    execution_count: int | None = None
    error: str | None = None

def output_text(outputs):
    "Flatten notebook outputs for tests, logs and plain terminal fallbacks."
    parts = []
    for out in outputs:
        kind = out.get('output_type')
        if kind == 'stream': parts.append(_text(out.get('text')))
        elif kind in ('execute_result', 'display_data'):
            data = out.get('data') or {}
            parts.append(_text(data.get('text/plain') or data.get('text/markdown')))
        elif kind == 'error':
            trace = out.get('traceback') or []
            parts.append('\n'.join(trace) if trace else f"{out.get('ename')}: {out.get('evalue')}")
    return '\n'.join(p.rstrip('\n') for p in parts if p is not None)

def _text(value):
    return ''.join(value) if isinstance(value, list) else str(value or '')
```

#| export
def hl(src):
    """`src` as highlighted `Text`, or plain `Text` if pygments cannot lex it.

    Never raises, and never returns anything whose `.plain` differs from `src`: the transcript
    copies out of `.plain`, so a highlighter that rewrote its input would hand back code that
    does not run.
    """
    src = str(src)
    if not src: return Text('')
    try:
        from rich.syntax import Syntax
        # `highlight` appends a newline -- it is built for whole files. Trimming it back is the
        # difference between a coloured prompt and a prompt one row taller than its line.
        out = Syntax(src, 'python', theme='gruvbox-dark').highlight(src)
        while out.plain.endswith('\n'): out.right_crop(1)
        return out if out.plain == src else Text(src)
    except Exception: return Text(src)
```

`right_crop` is unavailable, `Text(out.plain.rstrip('\n'), spans=out.spans)` is equivalent — the

#| export
def find_session(attach):
    """The base URL of a live Dhrishti session named `attach`, or `attach` itself if it is a URL.

    Through the registry rather than by re-serving. `serve_in_kernel` would return the right
    port for a kernel that is already serving -- and on the way there it reassigns the profile,
    the environment name and the agent mode, and repoints the session log directories. Attaching
    to somebody's session must not quietly widen it from `readonly` to `restricted`.
    """
    attach = str(attach).strip()
    if '://' in attach: return attach
    from dhrishti.serving import active
    entries = active()
    hit = next((e for e in entries if e.get('name') == attach), None)
    if hit is None and attach: hit = next((e for e in entries if attach in str(e.get('cwd') or '')), None)
    if hit is None: raise RuntimeError(
        f'no live dhrishti session matching {attach!r}; running: '
        f'{", ".join(str(e.get("name")) for e in entries) or "none"}')
    return hit.get('base') or f'http://127.0.0.1:{hit["port"]}'
```

**One thing an implementer will hit that the plan cannot pre-empt.** Task 6 puts an `enter` branch
ahead of `Ui.on_key`'s own `enter`, and `Ui.on_key` is defined twice — once in the class and once as
a `@patch` further down `05_cli.ipynb` that gives the transcript view priority. `PyreplUi.on_key`
must call `super().on_key(key)` and therefore reaches the patched version; the guards
(`self.ask is None`, `self.menu is None`, `not self.transcript.active`) exist so the new branch
never steals a key the patch needed. If a key goes missing in python mode, that interaction is
where to look first.

**Type consistency.** `describe()` is defined on `DhrishtiHost` in Task 8 Step 3 and reached
through `getattr(self.agent.host, 'describe', dict)()` in Step 5, so a `MemHost` in a test does
not break it. `find_session` returns a base URL string in both branches. `code_state` returns one
of exactly three literals, and every caller handles all three. `ExecOutcome.error` is `None` on
success everywhere it is read.
